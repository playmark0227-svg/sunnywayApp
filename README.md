# ☀️ Sunnyway

コスメブランドと**インフルエンサー**をつなぐ、Sunnyway のマッチングプラットフォーム。
**「ここに掲載すれば、何人ものインフルエンサーが取り上げます」** を軸に、掲載 → マッチング →
投稿 → 成果レポートまでを一気通貫で扱います。

> これは「まず一回動くものを」作った **第一版（MVP の土台）** です。実データのシード込みで、
> ログイン・権限分離・掲載作成・応募・承認・投稿提出・レポートまで一通り動きます。

---

## 🧭 コンセプトと登場人物

| 役割 | 立場 | 使う画面 | ログイン |
|---|---|---|---|
| **Sunnyway（運営）** | プラットフォーム所有者・管理者 | 管理 Web（PC 中心） | あり（ADMIN） |
| **コスメブランド** | 掲載してもらう顧客 | ― | **なし**（運営が代理） |
| **インフルエンサー** | 商品を取り上げる側 | アプリ（**スマホ専用**） | あり（INFLUENCER） |

### 設計上の決めごと（ヒアリング結果）
- **ブランドは管理画面に入れない**。ブランドは「ログインユーザー」ではなく運営が管理する
  `Brand` データとして保持し、掲載は運営が代理で作成する。
- **インフルエンサーの報酬**：ギフティング（現物提供）／金銭報酬の両対応（`RewardType`）。
- **Sunnyway の収益モデル**：月額・掲載料／キャンペーン課金／成果連動／販売手数料の
  **4 モデルを併用可能**（`BillingModel` を組み合わせて保持）。
- **インフルエンサーアプリはスマホ専用**。大画面でも常にモバイル幅で表示し、下部タブ UI。

## 🔐 セキュリティの考え方

ご要望の「管理者側は Web でセキュアに」「ブランドは管理権限に直接アクセスできない」を、
**多層防御**で担保しています。

1. **ロール分離（RBAC）**：`User.role` は `ADMIN` / `INFLUENCER` のみ。ブランドは
   ユーザーですらない。
2. **入口の分離**：管理 `/login`、インフルエンサー `/influencer/login` を分離。ログイン時に
   `expectedRole` を検証し、役割違いはログインさせない。
3. **二重ガード**：
   - Edge ミドルウェア（`middleware.ts`）が `/admin/*`・`/app/*` を一次防御。
   - 各保護**ページ自身**でも `requireAdmin()` / `requireInfluencer()` を先頭で再検証
     （レイアウト任せにせず、未認証時にデータがレスポンスへ混入するのを防止）。
   - サーバーアクションでも実行のたびに権限を再検証。
4. **セッション**：JWT を **httpOnly Cookie** に保存（`jose`）。本番は `secure` 付与。
5. **パスワード**：`bcryptjs` でハッシュ化。ログインはユーザー有無を区別しない応答。
6. **監査ログ**：`AuditLog` に管理操作（作成・承認など）を「誰が・いつ・何を」記録。

> 本番では `JWT_SECRET` を十分長いランダム値へ。さらに管理ドメインの分離・IP/VPN 制限・
> MFA・DB を PostgreSQL 等へ、という拡張余地を残しています。

## 🚀 セットアップ

```bash
# 1. 依存をインストール
npm install

# 2. 環境変数を用意（JWT_SECRET は適宜変更）
cp .env.example .env

# 3. DB を作成してシード投入
npm run db:push
npm run db:seed

# 4. 開発サーバ起動
npm run dev
# → http://localhost:3000
```

## 🔁 業務フロー（実装済み）

```
運営: 掲載(キャンペーン)作成  ─▶  インフル: 募集中から応募  ─▶  運営: 承認/却下
        ▲                                                          │
        │                                                          ▼
   レポート確認 ◀── 取り上げ(投稿)実績・リーチ集計 ◀── インフル: 投稿URLを提出
```

- 管理ダッシュボード：ブランド数・商品数・インフル数・募集中掲載・取り上げ件数・合計リーチ・監査ログ
- 掲載詳細＝**レポート**：「◯人のインフルエンサーが取り上げました／目標◯人／合計リーチ」、
  応募の承認・却下、投稿実績一覧、収益モデル表示、ステータス変更
- インフルアプリ：募集中フィード → 応募 → マイページで参加状況・投稿提出・プロフィール編集
